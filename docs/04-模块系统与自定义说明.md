# 04 · 模块系统与自定义说明

---

## 一、模块框架（哪些能动、哪些锁死）

站点由 6 个内置模块 + N 个自定义模块组成。**首屏锁第一位、联系方式锁最后一位**，这是硬约束，保证页面永远有开头和收尾。

| 模块 | key | 位置 | 可移除 | 可移动 | 小模块上限 |
| --- | --- | --- | --- | --- | --- |
| 首屏 | `hero` | 锁定第 1 | ✗ | ✗ | 行动按钮 3 |
| 个人档案 | `profile` | 中部 | ✓ | ✓ | 字段 6 / 指标 4 |
| 工作经历 | `experience` | 中部 | ✓ | ✓ | 8 条 |
| 精选项目 | `projects` | 中部 | ✓ | ✓ | 6 个 |
| 个人优势 | `capabilities` | 中部 | ✓ | ✓ | 6 张 |
| 联系方式 | `contact` | 锁定最后 | ✗ | ✗ | 外链 4 |
| 自定义模块 | `custom-*` | contact 之前 | ✓ | ✓ | 每类型 4 个 / 每种 8 块 |

### 位置约束的实现方式

```js
// src/content/site.config.js
locked: { first: 'hero', last: 'contact' },
limits: { ... }
```

`moveModule` 在移动时会**跳过锁定模块**，因此中部模块永远无法越过首末两端。这不是 UI 层面的按钮禁用，而是状态层的硬性拦截。

## 二、三种自定义模块

| 类型 | 适合放什么 | 每个子块的字段 |
| --- | --- | --- |
| **自由文本** `richText` | 证书、语言、培训、补充说明 | 小标题 + 正文（保留换行） |
| **图文卡片** `gallery` | 作品图、图表截图、证书照片 | 图片（4:3）+ 标题 + 说明 |
| **链接集合** `linkGrid` | GitHub、博客、知乎、公众号 | 名称 + 链接 + 一句话说明 |

### 怎么加

编辑 → **模块** → 添加自定义模块 → 选类型 → 填内容 → 自动保存。

### 加了之后在哪

统一插在"联系方式"**之前**，多个自定义模块之间可用上移 / 下移调整。

## 四、想加一种全新的模块类型

四步，不需要改核心逻辑。

### 第 1 步：在注册表登记

```js
// src/content/module.registry.js
export const CUSTOM_TYPES = [
  // ...已有的三种

  // 新增：数据表
  {
    type: 'table',
    label: '数据表',
    hint: '名称 + 数值 + 说明，适合放技能清单或指标明细',
    icon: 'grid',
    itemFields: [
      { key: 'heading', label: '名称', type: 'text' },
      { key: 'value',   label: '数值', type: 'text' },
      { key: 'body',    label: '说明', type: 'text' },
    ],
    blankItem: { heading: '', value: '', body: '' },
  },
];
```

### 第 2 步：加一个渲染组件

```jsx
// src/components/sections/CustomSection.jsx
function Table({ items }) {
  return (
    <table className="custom-table">
      <tbody>
        {items.map((it, i) => (
          <tr key={i}>
            <td>{it.heading}</td>
            <td className="num">{it.value}</td>
            <td>{it.body}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

### 第 3 步：在分发处接上

```jsx
// 同一个文件 CustomSection 内
{type === 'richText' && <RichText items={items} />}
{type === 'gallery'  && <Gallery items={items} />}
{type === 'linkGrid' && <LinkGrid items={items} />}
{type === 'table'    && <Table items={items} />}   // ← 新增
```

### 第 4 步：加样式

```css
/* CustomSection.css */
.custom-table { width: 100%; border-collapse: collapse; }
.custom-table td { padding: 10px 12px; border-bottom: 1px solid var(--line); }
```

编辑器表单会**自动生成**（它读 `itemFields` 渲染输入框），不需要额外写代码。

## 五、想加一个内置模块（如"作品集""推荐语"）

### 第 1 步：注册

```js
// module.registry.js → BUILTIN_MODULES
{
  key: 'testimonials',
  role: 'free',          // 可移除、可移动
  label: '推荐语',
  hint: '前同事或上级的一句话评价',
  anchor: 'testimonials',
}
```

### 第 2 步：加内容

```js
// resume.data.js
testimonials: {
  eyebrow: 'References',
  title: '推荐语',
  kicker: '来自合作过的同事。',
  items: [ { quote:'...', name:'...', title:'...' } ],
},
```

### 第 3 步：写组件并登记

```jsx
// src/components/sections/TestimonialsSection.jsx  ← 新建
// 然后在 App.jsx 的 SECTION_MAP 里加一行：
const SECTION_MAP = {
  // ...
  testimonials: TestimonialsSection,
};
```

### 第 4 步：加编辑器字段（可选）

在 `EditorPanel.jsx` 的 `ContentTab` 里加一组，写法照抄 `CapabilitiesFields`。

## 六、动效组件（ReactBits）使用说明

站点用了 7 个动效，其中 4 个是 ReactBits 官方源码（原样保留），3 个是零依赖等价实现。

| 组件 | 来源 | 位置 | 可调参数 |
| --- | --- | --- | --- |
| `Aurora` | ReactBits 官方 | `src/components/reactbits/Aurora.jsx` | `colorStops` `amplitude` `speed` `height` `glow` `brightness` `opacity` `dpr` |
| `DotGrid` | ReactBits 官方 | 同上 | `dotSize` `gap` `baseColor` `activeColor` `proximity` |
| `SpotlightCard` | ReactBits 官方 | 同上 | `spotlightColor` `intensity` `spotlightSize` `borderGlow` |
| `TiltedCard` | ReactBits 官方 | 同上 | `rotateAmplitude` `scaleOnHover` `glare` |
| `SplitTextLite` | 自研（零依赖） | `src/components/effects/` | `by` `stagger` `delay` |
| `CountUpLite` | 自研（零依赖） | 同上 | `to` `duration` `suffix` `decimals` |
| `useRevealGroup` | 自研钩子 | `src/hooks/index.js` | 阈值固定 |

### 为什么弃用官方 SplitText / CountUp / ScrollReveal

| 组件 | 官方依赖 | 体积代价 | 本页替代方案 |
| --- | --- | --- | --- |
| SplitText | gsap + @gsap/react | ≈ 90KB | CSS transition + 逐字 delay |
| CountUp | motion | ≈ 60KB | requestAnimationFrame + 缓动 |
| ScrollReveal | gsap | ≈ 70KB | 一个 IntersectionObserver 统一处理 |

本页只需要"入场一次"的动效，引入完整动画库不划算。替换后视觉等价，产物从 ~450KB 降到 233KB。

### 想调首屏背景强度

```jsx
// HeroSection.jsx
<Aurora
  colorStops={['#1E2530', '#7E8C74', '#0E1216']}  // 三段色：暗 / 亮 / 暗
  amplitude={0.55}    // 起伏幅度，越大越"浪"
  speed={0.34}        // 流动速度
  glow={0.16}         // 光晕，越大越发白（深色站建议 < 0.3）
  brightness={0.42}   // 整体亮度，越大越亮
  opacity={0.44}      // 叠加强度
  dpr={1.25}          // 分辨率倍数，越高越清晰也越耗性能
/>
```

> **重要**：Aurora 是 WebGL 着色器，本身不保证是深色。站点在它下面铺了一层 `.hero__base` 深色底 + `mix-blend-mode: soft-light`，所以无论着色器输出什么，首屏都是深色、文字都可读。改参数时不要把 `opacity` 提到 0.7 以上，否则会盖过底色。

## 七、性能与稳定性设计（已内置）

| 措施 | 位置 | 效果 |
| --- | --- | --- |
| Canvas 在页面不可见时暂停 | `usePageVisible` → `paused` | 切到后台不再耗电 |
| `dpr` 封顶 1.25–1.5 | HeroSection | 避免 4K 屏渲染 4 倍像素 |
| 移动端关闭倾斜/聚光/视差 | `useRichMotion` | `<900px` 或 `hover:none` 全部禁用 |
| 尊重系统"减弱动效" | CSS `prefers-reduced-motion` + JS 判断 | 全站动画降级为静态 |
| 入场动画兜底 | `useRevealGroup` 1.8s 超时 | 观察器失效也不会白屏 |
| 标题入场兜底 | `SplitTextLite` 2s 超时 | 同上 |
| 图片懒加载 | 所有 `<img>` 有 `loading="lazy"` | 首屏只加载 1 张 |
| 本地字体回退 | `tokens.css` 字体栈 | 外链失败版式不塌 |
| 存储失败提示 | `storage.js` 返回错误 | 配额满时明确告知，不静默丢数据 |

### 动效总开关

编辑面板 → 右上齿轮 → 外观 → **动效强度**滑块：

- `100%`：全部开启
- `40%` 以下：关闭倾斜与聚光，仅留入场淡入
- `0%`：全静态（等同系统"减弱动效"）

## 八、构建与部署

```bash
npm install          # 首次
npm run dev          # 本地开发，http://localhost:5173
npm run build        # 产物在 dist/
npm run preview      # 预览构建结果
```

`dist/` 是纯静态文件，可直接丢到任意静态托管（Vercel / Netlify / 对象存储 / Nginx）。

### 产物规模（实测）

| 文件 | 原始 | gzip |
| --- | --- | --- |
| HTML | 0.83 KB | 0.59 KB |
| CSS | 49.2 KB | 9.6 KB |
| JS | 233 KB | 79.9 KB |

首屏关键资源合计 gzip 后约 **90KB**，无需 CDN 也能快速打开。
