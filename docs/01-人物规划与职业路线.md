### 一句话定位

> **把模糊的业务问题，拆成可以被度量、被验证、被执行的指标。**

这句定位承担三个作用：区分于"只会跑 SQL 的取数岗"、区分于"只做图表的可视化岗"、为"业务型分析师"这一稀缺定位背书。

### 人设的三个支点（为什么可信）

1. **业务出身，不是纯技术出身。** 先做运营助理再转数据，意味着理解 GMV 背后的动作链条，而不是从表结构认识业务。这是初级分析师最稀缺的差异点。
2. **量化成果克制。** 不使用"提升 300%""赋能全链路"这类无法验证的表述，全部用百分点（pp）、时长、覆盖率等可核对口径。
3. **承认边界。** 算法建模标注为"可独立完成基础建模，复杂模型需协作"——初级岗位过度宣称算法能力，反而在面试中被追问击穿。

## 二、职业方向选择（依据 FineBI 四方向框架）

FineBI 将数据分析划分为四个主流细分方向。结合"入行不久 + 业务背景"的现实条件，做如下取舍：

| 细分方向 | 核心能力 | 年薪参考 | 对本人的适配判断 | 决策 |
| --- | --- | --- | --- | --- |
| **商业分析与 BI** | 业务理解、数据建模、指标体系、BI 工具 | 30–60 万 | 门槛中等，业务积累可直接复用，晋升路径清晰 | **主航道** |
| 数据挖掘与算法 | 机器学习、特征工程、编程 | 40–80 万+ | 技术门槛高，短期难以形成竞争力 | 辅助能力，不主攻 |
| 数据治理与管理 | 数据标准、元数据、合规 | 25–45 万 | 企业刚需但偏后台，初级岗位少 | 中期补课（指标体系治理） |
| 数据可视化 | 图表设计、交互开发、数据叙事 | 28–55 万 | 是"表达层"能力，不是独立职业路径 | 作为叙事载体强化 |

### 结论：一条主航道 + 两项加成

```
主航道   商业分析与 BI  ── 决定岗位匹配度与薪资区间
加成 A   数据可视化      ── 决定方案的说服力（同样的结论，讲得更清楚）
加成 B   数据治理（指标）── 决定能否从"做报表"升级为"定口径"
```

**为什么不是算法方向**：算法岗的竞争者是科班硕博与竞赛选手，1.5 年经验的业务型分析师在此赛道没有比较优势。但保留 Python + 基础建模能力，是为了在"预测类专题"中不被卡住，属于差异化补丁而非主攻方向。

## 三、四年路线图

### 阶段一 · 0–12 个月｜工具与口径（已完成）

- **目标**：能独立、准确地出数，理解每个指标的业务含义
- **交付物**：日报 / 周报自动化、口径文档、取数需求响应
- **验收标准**：口径零争议；出数时长达标；能解释指标异动的业务原因
- **风险点**：沦为"取数机器"——只接需求不问目的

### 阶段二 · 12–24 个月｜独立负责一条业务线（进行中）

- **目标**：从"给数"转为"给判断"
- **交付物**：业务线指标体系、周会决策看板、专题分析报告
- **验收标准**：至少 2 个专题结论被业务采纳并落地；看板成为周会固定议程
- **关键动作**：主动发起专题，而非等待需求；建立指标字典

### 阶段三 · 24–36 个月｜专题 Owner

- **目标**：独立负责一个完整业务命题（用户分层 / 留存 / 商品结构）
- **交付物**：从假设 → 实验设计 → 结论 → 落地追踪的完整闭环
- **验收标准**：能带 1 名实习生完成取数与初稿；结论进入业务 OKR
- **能力补课**：A/B 实验设计、因果推断基础、指标体系治理

### 阶段四 · 36 个月以后｜双通道

| 通道 | 目标岗位 | 所需补齐 |
| --- | --- | --- |
| 管理线 | 数据分析主管 / BI 经理 | 项目管理、跨部门推动、团队梯队 |
| 专家线 | 指标治理专家 / 数据产品经理 | 数据资产体系、数据产品设计、治理方法论 |

> **判断节点**：阶段三结束时，若"推动他人落地"比"自己深挖"更有成就感，走管理线；反之走专家线。这个判断不应提前到入行第一年做。

### 5.4 项目（精选 3 个）

**01 · 会员复购提升专题｜分层建模 + 策略实验**

- 背景：整体复购率连续两个季度下滑，运营侧缺乏干预抓手
- 做法：以 R/F/M 构建分层规则，识别"高价值流失预警"人群；设计 3 组触达实验（权益 / 内容 / 时机）
- 结果：目标人群复购率 +4.7pp；识别出"触达时机"为最强影响因子，替代原权益加码方案，节省预算约 18%
- 工具：SQL、Python（pandas）、FineBI

**02 · 商品结构优化｜ABC + 关联规则**

- 背景：SKU 数量两年翻倍，动销率持续下降
- 做法：ABC 分类结合关联购买分析，定位"高销量低毛利"与"低动销高库存"两类问题品
- 结果：滞销 SKU 占比 21% → 12%，库存周转天数缩短 9 天
- 工具：SQL、Excel（Power Query）

**03 · 投放 ROI 归因看板｜指标体系 + BI 落地**

- 背景：三条投放渠道口径不一致，无法横向比较
- 做法：统一定义 ROI / CAC / LTV 口径，建立渠道 × 层级的归因模型，落地为 FineBI 看板
- 结果：周会决策依据；预算调整周期由月缩短至周；口径争议归零
- 工具：FineBI、SQL
