# 03 · 内容修改指南

> 本文档面向"想改文案和图片，但不想碰组件代码"的使用者。
> 全程只需动 **一个文件**：`src/content/resume.data.js`

---

## 一、三种修改方式（按难易排序）

| 方式 | 适合谁 | 需要什么 | 改动是否持久 |
| --- | --- | --- | --- |
| **A. 页面上直接编辑** | 完全不懂代码 | 浏览器 | 存本浏览器 localStorage，换设备需导出 |
| **B. 改 `resume.data.js`** | 会一点代码 | 文本编辑器 | 持久，随代码走 |
| **C. 导出 / 导入 JSON** | 想备份或交接 | 浏览器 | 手动管理 |

> **推荐组合**：日常微调用 A，定型上线用 B，备份用 C。

---

## 二、方式 A：页面上直接编辑

### 操作路径

1. 打开站点 → 点右上角 **编辑**
2. 右侧出现编辑面板，三个标签：
   - **内容**：逐个模块改文案、换图、加删条目
   - **模块**：调整模块顺序、增删自定义模块
   - **数据**：导出 / 导入 / 清空 / 恢复
3. 改完会自动保存，**刷新不会丢**

### 各字段在哪

| 想改什么 | 位置 |
| --- | --- |
| 姓名、岗位、城市、求职状态 | 内容 → 基本信息 |
| 证件照 | 内容 → 基本信息 → 证件照（上传后自动裁 4:3） |
| 首屏大标题、定位一句话 | 内容 → 首屏文案 |
| 个人简介 | 内容 → 个人档案 |
| 联系方式（邮箱 / 电话 / 到岗时间） | 内容 → 个人档案 → 联系信息 |
| 4 个量化指标 | 内容 → 量化指标 |
| 工作 / 教育经历 | 内容 → 工作经历 |
| 3 个项目 | 内容 → 精选项目 |
| 4 张能力卡 | 内容 → 个人优势 |
| 收尾标题、邮箱按钮、外链 | 内容 → 联系方式 |

### 证件照规则（已自动处理）

- **固定 4:3**，上传任何比例的图都会被**居中裁剪**，不会拉伸变形
- 原图上限 **5MB**，处理后压到 **约 300–400KB**
- 处理在本地完成，**图片不会上传到任何服务器**
- 面板上会显示处理后的实际尺寸与体积

## 三、方式 B：改 `resume.data.js`（推荐用于定型）

### 文件位置

```
Web-Resume2/src/content/resume.data.js
```

### 改文案：直接替换字符串

```js
// 改前
person: {
  name: '林知远',
  role: '数据分析师',
},

// 改后
person: {
  name: '你的名字',
  role: '你的岗位',
},
```

### 改图片：两种做法

**做法 1（推荐）**：把图片放进 `public/`，然后写相对路径

```js
person: {
  avatar: '/my-photo.jpg',   // 对应 public/my-photo.jpg
}
```

**做法 2**：用页面编辑器上传（会存成 data URL，直接写进 localStorage）

> 图片建议先自行裁成 4:3、压到 500KB 以内再放 `public/`，首屏加载更快。

### 增删条目：改数组即可

```js
// 加一条工作经历
experience: {
  items: [
    { type:'work', period:'2025.03 — 至今', company:'拾光集', role:'数据分析师', points:[...] },
    // ↓ 新增
    { type:'work', period:'2024.03 — 2025.02', company:'某公司', role:'岗位', points:['...'] },
  ]
}
```

**注意**：数组长度有上限，超出的部分不会渲染。上限见 `site.config.js` 的 `limits`：

| 内容 | 上限 |
| --- | --- |
| 首屏按钮 | 3 |
| 联系信息字段 | 6 |
| 量化指标 | 4 |
| 经历条目 | 8 |
| 项目 | 6 |
| 能力卡 | 6 |
| 外链 | 4 |

### 改配色：`site.config.js`

```js
// src/content/site.config.js
export const THEMES = {
  graphite: { label:'石墨灰', bg:'#0B0C0E', elev:'#121417', accent:'#B8C4A8', accent2:'#C9A227' },
  // 加一套自己的：
  myTheme:  { label:'我的配色', bg:'#0D0F11', elev:'#15181C', accent:'#A8B8C8', accent2:'#D4A574' },
};
```

同时把 `theme.default` 改成 `'myTheme'`，页面默认就用这套。

### 改版心宽度

```js
layout: {
  container: 1200,   // 改成 1100 更紧凑，1400 更宽松
  prose: 68,         // 段落最大行长（字符数）
}
```

### 改完怎么生效

```bash
# 开发模式（改完自动刷新）
npm run dev

# 要发布
npm run build
```

## 四、方式 C：备份、迁移、分享

### 备份（重要）

1. 编辑 → **数据** → **导出 JSON**
2. 得到一个 `.json` 文件，含全部文案与图片
3. 换电脑 / 清缓存前务必先导出

> **提醒**：数据只存在你自己的浏览器里。清浏览器数据、换设备、换域名都会丢，除非导出过。

### 迁移到另一台设备

1. 旧设备：导出 JSON
2. 新设备：打开站点 → 编辑 → 数据 → **导入 JSON** → 选择文件

### 分享给别人填写

1. 把站点链接发给对方
2. 对方打开 → 编辑 → 数据 → **清空为空白模板**
3. 对方填自己的内容 → **导出 JSON** 保存

**为什么不做成"一条链接带内容"**：含图片时链接会长到被聊天软件截断，且内容会暴露在 URL 里。JSON 文件更可靠。

## 五、改文案的三条判断标准

这不是格式要求，是内容质量要求。简历页的读者只停留 30–90 秒。

### 1. 每条经历用"动作 + 口径 + 结果"

| ❌ 不要写 | ✅ 应该写 |
| --- | --- |
| 负责数据分析工作 | 维护 42 个核心指标、6 个指标域的口径字典 |
| 提升了用户复购 | 复购率 28.4% → 33.1%（+4.7pp） |
| 优化了报表流程 | 出数时长由每周 6 小时降至 40 分钟 |

**要点**：有基线、有终值、有时间范围。只有增幅没有基线，等于没说服力。

### 2. 数字必须能对上

- `4.7pp` 要和 `28.4% → 33.1%` 对得上
- `42 个指标`、`6 个指标域` 在多个地方出现时要一致
- 宁可写"约"，也不要编一个精确到小数点的假数

### 3. 不写不可验证的内容

主动不放进页面的：兴趣爱好、座右铭、自我评价、"精通 Office"、"抗压能力强"。

理由：招聘方无法验证，占位置但不提供判断依据。空出来的空间给项目结论。

## 六、常见问题

**Q：改了 `resume.data.js`，但页面还是旧内容？**
A：说明浏览器里有 localStorage 覆盖层。点 编辑 → 数据 → **恢复示例内容** 清除覆盖，或直接清站点数据。

**Q：上传的证件照显示不全？**
A：这是 4:3 居中裁剪的预期行为。若人物偏一侧，先自行裁好再上传。

**Q：导出的 JSON 很大？**
A：图片以 base64 存在 JSON 里。想减小体积，改用 `public/` 放图片 + 路径引用。

**Q：想把编辑入口藏掉，做成只读页给别人看？**
A：`src/content/site.config.js` → `features.editor: false`。

**Q：字体加载失败怎么办？**
A：字体是外链（Google Fonts）。失败会自动回退到系统字体（PingFang / 微软雅黑），版式不变，只是字形不同。要完全离线，删掉 `index.html` 里的 fonts 链接即可。
